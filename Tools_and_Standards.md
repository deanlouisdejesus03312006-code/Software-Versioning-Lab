1. Text Editor - Can be used for writing and editing code, where source code is first written in. (example, VS Code)

2. Terminal - Used for running commands like file directory navigation and executing code directly. (example, Bash)

3. Code Repository Host - Useful for storing project files, but more useful for collaboration purposes. (example, Github)

4. Testing Platform - Designed for testing software before publication. (example, Postman)

5. Version Tracking - Allows for taking snapshots of files periodically, ensuring there's a safe fallback when things go wrong. (example, Git)

Three coding standards

1. Use consistent naming conventions so that readers can easily understand what the purpose of things (variables, filenames) are.

2. Always have a fallback/save so that in case of interruptions, you can easily revert and not lose a lot of progress.

3. Either have self documenting code (good variable names, little to no obfuscation) or detailed documentation so that collaboration with other people will be easier.
